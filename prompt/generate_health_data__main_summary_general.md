# 睡眠主摘要

用自然口语说明「为什么是这个睡眠标签」。**只输出一个 JSON**，不要 markdown 围栏、不要前后废话：

`{"title":"<与输入一致>","summary":"<一段中文>"}`

- `title`：与文末 JSON 顶层 `title` **逐字相同**。
- `summary`：至少 **2 个**可核对的具体数字，必须来自文末 `sleep_data.raw_data`（若是「抗扰宗师」则主要依据 `sleep_events` 里的信息，可辅以 raw_data 中与「干扰后仍睡得稳」直接相关的少量指标）。**禁止**编造、禁止照抄任何示例里的假数字；**唯一下方 JSON 是事实来源**。
- 数字和评价要揉在一起写，不要「先一串数再一句总结」的清单感；不要引用 `idf_data` 里的具体时段；不要出现 sleep_score /「睡眠评分」；不要用「本次监测/睡眠/记录」起头；不要延伸就医建议。
- **时间与事件措辞**：写当晚出现的干扰/异常，用「昨晚」「夜里」「这一晚」「入睡后」等；避免以「曾检测到…」起句（易被理解成很久以前）。同类意思任选自然说法，不必固定一句式。
- **勿写「翻身次数」**：摘要中不要出现「翻身次数」「整夜翻身 X 次」「翻身仅 X 次」等表述；**不要**把 `raw_data.turnover_count` 口语化成任何「计次翻身」说法（产品对外不强调该维度）。写夜间躁动、睡不安稳时，用清醒占比、效率、碎片化等可核对指标或事件描述，**不要**用翻身计次凑论据。

**先看清 `title` 再选角度（内容要对，写法每次换样）**

| title | 叙事应围绕 |
|-------|------------|
| 深睡守护者 | 深睡占比等 |
| 秒睡王者 | 入睡用时为主，其余指标点到为止、为秒睡服务即可 |
| 夜眠不安 | 入睡偏慢、清醒占比、浅睡偏高、睡眠碎片化等；**勿写翻身次数/计次翻身** |
| 浅眠易醒 | 浅睡偏多等 |
| 眠质不良 | 多项指标综合不佳 |
| 抗扰宗师 | **以睡眠事件为主**（昨晚/夜里检测到的干扰等），辅以清醒占比、睡眠效率等；勿展开分期式深睡/浅睡分析；**勿用翻身计次**论证抗扰 |

**去模板化**：同一段话里避免「指标A + 指标B + 让你获得XX标签」这种固定骨架；收尾点明标签即可，**换用不同说法**（不必每次「这就是你获得…的原因」）；起笔可从感受、现象或最关键的一个数切入，**不要套同一开场**。

**禁止**：空泛夸「各项正常」、纯逗号罗列无判断、全文复读标签名超过必要次数。
