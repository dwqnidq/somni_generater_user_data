# output 数据文件说明

本文档说明 `output/` 目录中现有 JSON 数据文件的用途与结构。目录中大量文件以 `{uid}_{数据类型}.json` 命名，表示同一类数据按不同用户分别生成；下文按“数据类型”归类说明，每类只给一条代表性结构。

> 统计口径：当前目录共有 107 个 JSON 数据文件，归为 20 类结构。`*_baseline.json` 表示事件回填或调整前的基线数据，结构与对应非 baseline 文件一致。

## 命名约定

| 命名形式 | 含义 |
| --- | --- |
| `{uid}_health_data.json` | 某个用户的日级睡眠健康数据 |
| `{uid}_vitals_data.json` | 某个用户的夜间体征采样数据 |
| `{uid}_environment_data.json` | 某个用户的夜间环境采样数据 |
| `{uid}_sleep_events.json` | 某个用户的睡眠事件数据 |
| `{uid}_calendar_events.json` | 某个用户的日程数据 |
| `{uid}_*.json` | 其他按用户拆分的数据文件 |
| `somni_*.json` / `beijing_*.json` | 睡眠地图或聚合类数据 |
| 无 uid 前缀文件 | 全局配置、索引、路由、天气或方案类数据 |
