# 异常事件干预方案

## 持续性噪音干预方案


| 干预类型 | 具体参数                                                        | 科学依据                       |
| ---- | ----------------------------------------------------------- | -------------------------- |
| 光    | 全程 0 lux（或保持触发阶段的光照状态，不改变）                                  | 避免光线干扰睡眠，聚焦声掩蔽             |
| 声    | 布朗噪音稳态掩蔽；S/W 阶段均为叠加；响应速度：500 ms 内启动；音量最大 = 环境噪音值 −5 dB，线性抬升 | 布朗噪音对稳态干扰掩蔽效率最优，线性调整避免二次刺激 |
| 味    | 全程关闭（0 浓度）                                                  | 夜间嗅觉刺激易引发觉醒，无需额外干预         |

## 一次性噪音干预方案


| 干预类型 | 具体参数                                                                                                        | 科学依据                        |
| ---- | ----------------------------------------------------------------------------------------------------------- | --------------------------- |
| 光    | 全程 0 lux（或保持触发阶段的光照状态，不改变）                                                                                  | 突发噪音后光线易加剧应激反应              |
| 声    | 响应速度：500 ms 内启动；频段：低频布朗噪音；声级：突发噪音峰值 −10 dB（≤35 dB）；时序：峰值保持 30 s → 线性淡出 3 s，每秒递减 5 dB 至干预前音量；后掩蔽：保留 5 s 平稳掩蔽 | 低频布朗噪音针对性掩蔽脉冲噪音，后掩蔽防止听觉回弹惊醒 |
| 味    | 全程关闭（0 浓度）                                                                                                  | 无嗅觉干预必要                     |

## 难以入睡干预方案


| 干预类型 | 具体参数                                                                                                                                                                    | 科学依据                                              |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 光    | 采集：实时监测当前呼吸频率；同步呼吸：从当前的呼吸频率开始，做灯光的明暗变化，逐渐接近 4 s 吸、6 s 呼的呼吸频率；引导目标：6 次/分钟；光变规则：吸气 0 lux→4 lux（对数渐亮）4 s，呼气 4 lux→0 lux（对数渐暗）6 s；周期：完全匹配呼吸周期，随呼吸变慢同步拉长；最大亮度 ≤4 lux；无频闪、无跳变 | 光呼吸同步引导可降低交感神经活性，4 lux 为褪黑素无干扰阈值，缓慢渐变避免刺激         |
| 声    | U/S 阶段专属布朗噪音；音量 22 dB 恒定                                                                                                                                                | U/S 阶段专属布朗噪音（适配睡前放松、入睡场景），恒定低频声波辅助放松，同步节奏强化呼吸引导效果 |
| 味    | 薰衣草喷 5 秒停 30 秒（后续根据实际体验调整）                                                                                                                                              | /                                                 |

## 噩梦应激干预方案


| 干预类型 | 具体参数                                                                      | 科学依据                                       |
| ---- | ------------------------------------------------------------------------- | ------------------------------------------ |
| 光    | 全程 0 lux（或保持触发阶段的光照状态，不改变）                                                | 夜间强光易加剧应激反应，保持黑暗安抚情绪                       |
| 声    | 布朗噪音（原掩蔽噪音）；音量小于 25 dB 则提升到 25 dB，高于 25 dB 则保持不变；淡入/淡出时长 10 s，总干预时长约 30 s | M 阶段专属布朗噪音可降低杏仁核活性，缓解恐惧情绪，契合夜间守护场景，短时适配体验版 |
| 味    | 薰衣草；薰衣草喷 1 秒停 10 秒                                                        | 薰衣草香气可降低皮质醇水平，辅助情绪平复，线性缓释避免刺激              |

## 异常体动干预


| 干预类型 | 具体参数                                 | 科学依据                                                   |
| ---- | ------------------------------------ | ------------------------------------------------------ |
| 光    | 全程 0 lux                             | M 阶段强制无光，避免刺激                                          |
| 声    | 布朗噪音恒定掩蔽；音量 22–25 dB；无波动，淡入/淡出时长 3 s | M 阶段专属布朗噪音可抑制体动引发的觉醒，稳定夜间睡眠状态，契合 M 阶段声音标准，10 s 渐变适配体验版 |
| 味    | 全程关闭                                 | M 阶段无嗅觉干预必要                                            |

## 心率上升干预方案


| 干预类型 | 具体参数                                                      | 科学依据                                              |
| ---- | --------------------------------------------------------- | ------------------------------------------------- |
| 光    | 全程 0 lux                                                  | 无光刺激可降低交感神经兴奋度                                    |
| 声    | 布朗噪音（30 dB），如原阶段有噪音则原阶声音下降至 30 dB，结束后回升；恒定无波动；淡入/淡出时长 3 s | S/M 阶段专属布朗噪音（适配入睡、夜间场景），低强度稳态声波可抑制心率过快，避免节奏变化加重应激 |
| 味    | 低浓度薰衣草（≤0.1%）；缓慢缓释，淡入/淡出时长 3 s                            | 薰衣草成分可调节自主神经，辅助心率回落，线性缓释避免刺激                      |
