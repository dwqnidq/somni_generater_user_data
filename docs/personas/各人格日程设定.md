# 各人格日程设定

> 基于 `各人格睡眠指标范围.md` 的四维编码。**M/E** 定精力高峰时段；**H/L**（活跃度，`H` 高活跃 / `L` 低活跃）定日程负荷与收束节奏；**R/C**（敏感度，`R` 低敏 / `C` 高敏）定环境稳态与恢复缓冲；**U/S/M/W** 定核心睡眠痛点（`U` 不易关机、`S` 无明显痛点、`M` 易醒难接觉、`W` 起床偏晚）。  
> **有效日程**：有明确产出 / 对象 / 目的；**表内只列有效日程**，午餐、独处、静默留白等不写进表，在节下用文字说明即可。  
> **早上日程**：M 为 06:00–09:00；E 为起床后首段轻量（约 09:30–12:00）。**首条日程**：时段可不变，**文案刻意写短**，便于扫读。  
> **有效日程条数**（每人格两天示例中单日条数一致）：**仅由 H/L 与 R/C 决定**——`H+R` **8** 条；`L+R` **6** 条；`H+C` **5** 条；`L+C` **3** 条。同组合人格条数相同；M/E 与 U/S/M/W 只影响时段与任务类型，**不改变条数**。

## 通勤办公型锚点日程（可复用模板）

> 适用于需要稳定昼夜节律、以跨团队协作为主的工作日。  
> 用法：优先固定锚点时段，再按人格特征替换具体任务主题和强度。

### 固定锚点（工作日可用）

| 时间          | 日程内容                         | 目的 |
| ------------- | -------------------------------- | ---- |
| 06:40–07:10   | **拉伸与低强度活动**             | 平稳唤醒，降低高刺激带来的状态波动 |
| 09:00–09:30   | **晨间对齐会议**                 | 同步任务边界与优先级，减少临时沟通 |
| 13:30–14:00   | **需求评审与信息确认**           | 为下午执行阶段降噪，减少反复 |
| 20:30–21:30   | **阅读与放松（低刺激活动）**     | 夜间过渡，逐步降低感官输入 |

### 可选会议锚点（按实际需要启用）

| 时间          | 日程内容                 | 目的 |
| ------------- | ------------------------ | ---- |
| 11:30–12:00   | **跨部门沟通会议**       | 集中处理协作关键问题，避免全天碎片化打断 |
| 15:00–16:00   | **周复盘会议**           | 总结关键问题与处理路径，降低长期不确定性 |
| 16:00–17:00   | **进度同步会议**         | 阶段校准，避免任务偏移 |

### 套用建议（按人格微调）

- **M（晨型）**：保留 `06:40–07:10` 与 `09:00–09:30`，把高认知任务放在 09:30–12:00。  
- **E（晚型）**：晨间锚点改为「起床后 30 分钟低强度启动」，核心产出转移到 14:00 以后。  
- **H（高活跃）**：在 `09:30–12:00`、`14:00–17:00` 的重任务块中间加 20–30 分钟缓冲。  
- **L（低活跃）**：保持锚点不变，减少同一时段并行目标。  
- **C（高敏）**：会议后增加 15–30 分钟独处整理，夜间段避免信息输入过载。  
- **R（低敏）**：可将沟通与产出任务相邻安排，但保留晚间低刺激收束段。
