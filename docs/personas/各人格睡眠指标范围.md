# 各人格睡眠指标范围（基于四维人格编码）

> 规则来源：`睡眠指标标准.md`；三维编码释义以 `docs/reference/睡眠人格编码说明.md` 为准。  
> 四维编码解释：`M/E`=晨型/夜型；`H/L`=**活跃度**（`H` 高活跃 / `L` 低活跃）；`R/C`=**敏感度**（`R` 低敏感 / `C` 高敏感）；`U/S/M/W`=核心睡眠痛点（可选第四位，**不写入「人格特征」列**）。  
> 核心痛点解释（仅用于其它指标与叙事，不映射到「人格特征」文案）：`U`=大脑不关机，`S`=无明显睡眠痛点，`M`=半夜易醒且难以接觉，`W`=早上起不来/起床时间晚。  

> 设定原则：  
> - **（最高优先级）必须符合人格特征**：所有指标须能用 `M/E`、`H/L`、`R/C`、可选第四位编码及该人格「好=稳定态 / 差=失衡态」叙事自洽解释；不得为追求"更健康"而削弱人格差异。  
> - 核心目标是"人格一致性"，`好/差` 都先符合人格特征，不以"健康分级"作为唯一标准。  
> - `好`=该人格稳定态，`差`=该人格失衡态（同人格内对比）。  
> - `E` 相比 `M` 整体起卧更晚。  
> - **卧床时间点、起床时间点**：须与各项指标**联立可行**（任何独立采样下 `总睡+入睡+清醒 ≤ 最小在床时间`）。**晨型 `M`**：卧床控制在 **21:30–21:45**，起床控制在 **07:15–07:30**（闭区间；为保证下游独立采样不越界，最小 TIB 达 570）。**夜型 `E`** 可更晚卧起且**窗整体更宽**：差态卧床窗 ≥ 2.5 小时，起床窗 ≥ 2.5 小时（最小 TIB 扩容至 630 分钟以上，以容纳 E 失衡时的各种拖延）。  
> - **总睡眠分钟数**：**闭区间**；**`C`（高敏感）**落在 **[420, 480]**；**`R`（低敏感）**落在 **[481, 540]**。在 **`H/L` 与 `R/C` 相同**的前提下 **`M` 严格高于 `E`（无交叉）**。**晨型 `M` 的区间跨度（3-5分）严格小于夜型 `E`（10-11分）**。**同人格内「好」下界严格高于「差」上界 30 分钟量级**。  
> - **平均心率、平均呼吸率**：在 **`M/E` 与 `H/L` 相同**的前提下，**`R` 严格低于 `C`**；在 **`H/L` 与 `R/C` 相同**的前提下，**`E` 严格高于 `M`**。  
> - **入睡分钟数**：同 `M/E` 与 `R/C` 时，**`H` 严格长于 `L`**；同 `H/L` 与 `R/C` 时，**`E` 严格长于 `M`**。  
> - **觉后清醒时间**：同 `M/E` 与 `H/L` 时，**`R` 严格低于 `C`**；同 `H/L` 与 `R/C` 时，**`E` 严格高于 `M`**。  
> - 痛点约束：`U` 拉高入睡潜伏期；`M` 拉高夜间清醒次数与时长；`W` 推迟起床时间；`S` 结构更均衡。  
> - **夜间总清醒分钟数**：同 `R/C` 时 **`M` 严格低于 `E`（无交叉）**；同 `M/E` 时 **`R` 严格低于 `C`（无交叉）**；同 `M/E` + `R/C` 组合下，允许 `H/L` 带有自然差异（L 略低于 H）。  
> - **睡眠结构比例**：同 `M/E` 与 `H/L` 时，**`R` 深睡/REM 占比高于 `C`**；同 `H/L` 与 `R/C` 时，**`M` 深睡/REM 占比高于 `E`**。
