# 各人格睡眠指标范围（基于三维人格编码）

> 规则来源：`睡眠指标标准.md`  
> 三维编码解释：`M/E`=晨型/夜型，`H/L`=高敏/低敏，`R/C`=高活跃/低活跃。  
> 设定原则：  
> - **（最高优先级）必须符合人格特征**：所有指标（含起床/卧床/实际入睡时刻、觉后清醒、潜伏期、心率呼吸与结构比例等）须能用三维编码 `M/E`、`H/L`、`R/C` 及该人格「好=稳定态 / 差=失衡态」的叙事自洽解释；不得为追求“健康”或“节律更窄”而削弱人格间应有的差异。  
> - 核心目标是“人格一致性”，`好/差` 都先符合人格特征，不以“健康分级”作为唯一标准。  
> - `好`=该人格的稳定态，`差`=该人格的失衡态（同人格内对比）。  
> - `E` 相比 `M` 整体起卧更晚；`H` 的清醒相关指标更高；`R` 的心率/呼吸略高、认知唤醒水平较高，入睡相对较慢；`C` 神经系统更平稳，入睡相对较快。  
> - `M`（晨型）：在**满足上条人格约束**的前提下，起床、卧床、实际入睡及觉后清醒等时钟相关区间相对 `E` 更窄，体现早睡早起与节律较稳，但仍保留小幅波动（非单点固定）。
>
> **表格读法**：每位人格占两行（差、好）；第二行**人格名称、人格编码、人格特征、身份类型**四列为空，表示与上一行合并为同一人格。
