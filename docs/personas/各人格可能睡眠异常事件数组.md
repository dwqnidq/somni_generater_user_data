## 分配规则（便于后续脚本化）

| 维度 | 倾向事件 |
| --- | --- |
| `U`（大脑不关机） | `入睡困难`、`噩梦应激`、`心率上升` 优先级上调 |
| `M`（半夜易醒难接觉） | `异常体动`、`心率上升`、`噩梦应激` 优先级上调，并叠加环境噪声类 |
| `W`（起床晚） | 以 `异常体动`、`心率上升`、部分环境持续声为主，避免过多“入睡困难” |
| `S`（无明显痛点） | 异常事件总量收敛，仅保留低频轻中度异常 |
| `C`（高敏感） | 环境噪声类（持续声/突发声）更易出现 |
| `R`（低敏感） | 环境噪声类减少，更多为内源性异常（入睡困难/体动/心率波动） |
