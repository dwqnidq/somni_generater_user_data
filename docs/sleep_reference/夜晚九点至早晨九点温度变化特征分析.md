# 夜晚九点至早晨九点温度变化特征分析

## 1. 概述
本文档旨在描述一个典型晴好天气条件下，从夜晚 21:00 至次日早晨 09:00 这十二个小时内的环境温度变化趋势及体感特征。

## 2. 温度变化阶段划分

### 第一阶段：快速降温期 (21:00 - 24:00)
- **时间范围：** 21:00 - 00:00
- **温度趋势：** 显著下降
- **变化描述：**
    - **21:00** 左右，太阳辐射已完全消失，地面开始以长波辐射形式向外散失热量。此时温度虽较白天有所回落，但地表仍存有一定积温，体感相对舒适。
    - **22:00 - 23:00**，降温速率达到夜间峰值。地面热量入不敷出，气温以每小时约 1-2°C 的速度下滑，夜凉如水的感觉逐渐明显。
    - **00:00**，气温通常已降至较傍晚低 4-6°C 的水平。

### 第二阶段：低温维持与谷底期 (00:00 - 06:00)
- **时间范围：** 00:00 - 06:00
- **温度趋势：** 缓慢下降并探底
- **变化描述：**
    - **00:00 - 04:00**，降温速率放缓。此时大气层结趋于稳定，近地面冷空气堆积，湿度上升，露点温度接近，易形成辐射雾或轻雾。
    - **04:00 - 06:00**，**一日气温最低点**通常出现在此时间段（日出前后）。地面经过一整夜的辐射冷却，热量储存达到极小值。此时体感最为寒冷，若遇晴朗无风天气，还可能出现霜冻或地面凝结水。

### 第三阶段：日出转折与快速回暖期 (06:00 - 09:00)
- **时间范围：** 06:00 - 09:00
- **温度趋势：** 止跌回升
- **变化描述：**
    - **06:00 - 07:00**，随着太阳高度角越过地平线，太阳短波辐射开始注入能量。但此时辐射收入尚不足以抵消地面散热，**气温仍在谷底徘徊**，甚至可能出现“日出后一小段时间体感更冷”的现象。
    - **07:00 - 08:00**，辐射收支由负转正，气温曲线迎来明显拐点，温度开始快速拉升。
    - **08:00 - 09:00**，升温进入快车道。地面和空气被迅速加热，露水蒸发消散，体感从湿冷转为干暖，预示着白天气温的全面回升。

## 3. 数据模拟曲线参考 (示意)
若以晴朗微风夜晚为例，温度走势大致如下：

| 时间节点 | 相对温度趋势 (假设基准) | 关键气象现象 |
| :--- | :--- | :--- |
| 21:00 | 15°C (起始参考点) | 地面长波辐射主导 |
| 00:00 | 11°C (↓ 4°C) | 降温显著 |
| 03:00 | 9°C (↓ 2°C) | 湿度上升，或有轻雾 |
| 06:00 | 8°C (↓ 1°C) | **气温谷底，霜点/露点** |
| 07:00 | 8.5°C (缓慢回升) | 日出，体感仍冷 |
| 09:00 | 12°C (快速拉升) | 露水蒸发，回暖明显 |

## 4. 影响夜间温度变化的主要因子
1.  **云量：** 云层像棉被，多云夜晚地面辐射散热受阻，**降温慢**，最低温较高；晴朗夜晚降温快，**昼夜温差大**。
2.  **风力：** 静风利于冷空气下沉堆积（局部低温）；微风可促进上下层空气混合，减缓地表降温速率。
3.  **湿度与地形：** 山谷、洼地易形成“冷湖效应”，夜间温度远低于同海拔山坡。
