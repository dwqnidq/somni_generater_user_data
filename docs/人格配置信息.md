## 关键口径说明（生成与校验一致）

### 「清醒比例」vs「夜间清醒总分钟数」

- **清醒比例（awake%）**：以 **TIB（上床 `bed_time` → 起床 `wake_up_time`）** 为分母的清醒占比；用于推导**本晚总清醒分钟数**（含入睡前、夜间中段、觉后清醒）。
- **夜间清醒总分钟数（nightWakeTotalMinutes / WASO）**：指 **入睡后中段清醒累计**（WASO），即 `sleep_time` → `wake_time` 区间内的清醒分钟，**不包含**：
  - 上床 → 入睡（入睡潜伏期的首段清醒）
  - `wake_time` → `wake_up_time`（觉后清醒的末段清醒）

### 如何在输出 `health_data.json` 中核对「夜间清醒总分钟数」

以 `idf_data` 为准，按如下规则求和：

- 取 `idf_data` 中所有 `stage == "awake"` 的段
- 去掉第 1 段（首段，通常为入睡潜伏期清醒）
- 去掉最后 1 段“觉后清醒”（其 `start` 通常与 `raw_data.wake_time` 的本地 `HH:MM` 对齐）
- 其余 awake 段分钟数求和 = **夜间清醒总分钟数（WASO）**

### 配置冲突时的处理优先级（重要）

当用户配置的 **`nightWakeTotalMinutes`** 目标（WASO）与 **`awakeSleep` 清醒比例上限**在给定 TIB 下不可同时满足时：

- 生成逻辑会**优先保证** WASO 落入 `nightWakeTotalMinutes` 区间（且满足夜间醒来次数对应的最小分钟约束）
- 必要时会在计算阶段**临时放宽**可用清醒比例上限（最高到 97%）以达到目标

如果你希望清醒比例也**严格不超过** `awakeSleep.max`，请确保 `awakeSleep` 的上限与 `nightWakeTotalMinutes` 在典型 TIB 下**可同时满足**。

# 八种人格的睡眠过程详解

每种人格的睡眠过程由以下阶段组成：**清醒 → 浅睡 → 深睡 → REM**，循环 4-5 个周期，每个周期约 90 分钟。

健康睡眠的参考标准：
- 深睡：20-25%
- REM：20-25%
- 浅睡：约 50%
- 清醒：< 5%
- 入睡潜伏期：< 20 分钟
