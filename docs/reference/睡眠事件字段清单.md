## AI主动干预事件补充

`AI主动干预` 是在异常事件后自动生成的配对事件：

- `event_type`: `AI主动干预`
- `code`: 与前一个异常事件相同（例如 `sleeping` / `nightmare` / 噪音类 code）
- `type`: 与前一个异常事件相同（通常为 `abnormal`）
- `detail` 结构固定为：
  - `trigger_cause`: 系统检测到xxx警报（按事件类型映射）
  - `action_taken`: 根据干预模板或大模型生成的执行文案
  - `result_summary`: 按事件类型映射的干预结果文案
