# 各输出 JSON 数据结构一览

本文档描述流水线生成的各数据文件**单条记录**字段含义与类型；与 `docs/appleHealth.md` 对齐的体征 `metrics` 扩展字段见「vitals_data」一节。

---

## 1. `health_data.json`（睡眠健康，按日一条）

### 1.1 文档约定中的顶层结构

对接文档中睡眠记录以以下字段为主：


| 字段            | 类型     | 说明                                      |
| ------------- | ------ | --------------------------------------- |
| `user_id`     | string | 用户 ID                                   |
| `record_date` | string | 业务日 `YYYY-MM-DD`                        |
| `raw_data`    | object | 睡眠摘要指标与时间字段                             |
| `idf_data`    | array  | 睡眠分期片段，`{ stage, start, end }`（`HH:MM`） |
| `create_time` | string | ISO 8601 UTC                            |
| `update_time` | string | ISO 8601 UTC                            |


**说明：** 实际文件中还常见 `timestamp`、`dimension_type`、`data_source`、`__v` 等字段，用于兼容既有存储与维度标记；对接时可视需求一并处理。

### 1.2 `raw_data`（文档列出的字段）

下表为**文档侧**应展示的 `raw_data` 子字段（不含离床/翻身统计，见脚注）。


| 字段                    | 类型     | 说明               |
| --------------------- | ------ | ---------------- |
| `apnea_count`         | int    | 呼吸暂停相关计数         |
| `average_heartbeat`   | int    | 平均心率             |
| `average_respiration` | int    | 平均呼吸率            |
| `awake_ratio`         | int    | 清醒占 SPT 比例（%）    |
| `deep_sleep_ratio`    | int    | 深睡占 SPT 比例（%）    |
| `light_sleep_ratio`   | int    | 浅睡占 SPT 比例（%）    |
| `rem_ratio`           | int    | REM 占 SPT 比例（%）  |
| `sleep_score`         | int    | 睡眠综合分            |
| `total_sleep_minutes` | int    | 总睡眠分钟数           |
| `bed_time`            | string | 上床时间（ISO UTC）    |
| `sleep_time`          | string | 入睡时间（ISO UTC）    |
| `wake_time`           | string | 醒来时间（ISO UTC）    |
| `wake_up_time`        | string | 起床/离床时间（ISO UTC） |
| `sleep_latency`       | int    | 入睡潜伏期（分钟）        |
| `sleep_efficiency`    | int    | 睡眠效率（%）          |


**脚注（生成与文档差异）：** 生成程序仍在 `raw_data` 中写入 `leave_bed_count`、`leave_bed_minutes`、`turnover_count`；**本文档不将上述三项列入对接字段表**，但 JSON 中仍存在，解析端若不需要可忽略。

## 2. `vitals_data.json`（夜间雷达体征采样）


| 字段             | 类型     | 说明                          |
| -------------- | ------ | --------------------------- |
| `uid`          | string | 用户 ID                       |
| `record_date`  | string | `YYYY-MM-DD`                |
| `collected_at` | string | 采样时刻 UTC，`...Z`             |
| `data_source`  | string | 如 `radar`                   |
| `metrics`      | object | 体征与 Apple Health 文档维度扩展，见下表 |
| `device_id`    | string | 设备 ID，可为空串                  |
| `create_time`  | string | 本地格式 `YYYY-MM-DD HH:mm:ss`  |
| `update_time`  | string | 同 `create_time`             |
| `session_id`   | string | 流水线写回，可为空串                  |


部分历史/入库文件可能含 `_id`，以实际文件为准。

### 2.1 `metrics`（核心雷达 + `docs/appleHealth.md` 对齐字段）


| 字段                               | 类型     | 说明                        |
| -------------------------------- | ------ | ------------------------- |
| `respiration_rate`               | int    | 呼吸率                       |
| `heart_rate`                     | int    | 心率                        |
| `body_motion_level`              | int    | 体动等级                      |
| `blood_oxygen`                   | int    | 血氧                        |
| `blood_pressure_systolic`        | int    | 收缩压                       |
| `blood_pressure_diastolic`       | int    | 舒张压                       |
| `hrv`                            | int    | 心率变异性                     |
| `noise_exposure_db`              | int    | 噪音暴露水平（分贝），随分期略变          |
| `hand_washing_count`             | int    | 洗手次数（夜间采样为 0）             |
| `sun_exposure_minutes`           | int    | 日照分钟（夜间为 0）               |
| `standing_minutes`               | int    | 站立时间（分钟，夜间为 0）            |
| `stand_time_minutes`             | int    | Stand Time（与站立一致语义，夜间为 0） |
| `exercise_time_minutes`          | int    | 运动时间（夜间为 0）               |
| `mindful_session_minutes`        | int    | 正念训练时长（夜间为 0）             |
| `mindfulness_meditation_minutes` | int    | 正念/冥想合并时长（夜间为 0）          |
| `mood_score`                     | int    | 情绪分（约 1–5）                |
| `stress_level`                   | int    | 压力水平（约 1–10）              |
| `step_count`                     | int    | 步数（夜间为 0）                 |
| `walking_running_distance_m`     | float  | 行走和跑步距离（米，夜间为 0）          |
| `flights_climbed`                | int    | 爬楼层数（夜间为 0）               |
| `active_energy_kcal`             | float  | 活动消耗卡路里（夜间为低代谢占位）         |
| `workout_record`                 | string | 锻炼记录摘要（夜间为空串）             |
| `running_cadence_spm`            | null   | 步频（spm），夜间无运动为 null       |
| `running_pace_min_per_km`        | null   | 配速（分/公里），夜间为 null         |
| `gps_route`                      | null   | 运动路线 GPS，夜间为 null         |

## 4. `sleep_report.json`（睡眠报告）


| 字段                    | 类型     | 说明                     |
| --------------------- | ------ | ---------------------- |
| `uid`                 | string | 用户 ID                  |
| `record_date`         | string | `YYYY-MM-DD`           |
| `main`                | object | 标题、配图 URL、摘要等          |
| `sleep_summary`       | object | 身体电量、总时长、深睡分钟、平均心率/呼吸等 |

| `quality_analysis`    | object | 质量分析模块等                |


子结构字段较多，以生成代码与样例 JSON 为准。
