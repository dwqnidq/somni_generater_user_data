# 项目数据结构总览

本文档汇总本仓库内**主要 JSON 文件与流水线产物**的字段结构；与睡眠分期、报告子模块等实现细节以 `scripts/generate_data/generate_health_data.py` 及样例 `output/`、`output_backup/` 为准。更精简的对接表可参考同目录下的 `数据文件结构表.md`。

---

## 0. 文件与产物索引


| 类别      | 路径或文件名模式                                                                | 说明                           |
| ------- | ----------------------------------------------------------------------- | ---------------------------- |
| 用户与生成配置 | `config/config.json`                                                    | `user_profiles` 数组，驱动单用户全量生成 |
| 单用户输出   | `output/{user_id}_*.json`                                               | 健康、日程、事件、报告等                 |
| 人格批量样例  | `output/all_personality_health_data.json`                               | 8 人格 × 4 条健康样例               |
| 人格方案文档  | `output/all_personality_profiles.json`                                  | 32 条（8×4 维）助眠方案配置            |
| 事件回填审计  | `output/{user_id}_event_feedback_report.json`                           | 睡眠事件驱动改数日志                   |
| 音频清单    | `qiniu/audio.json`、`qiniu/old_audio.json`、`qiniu/downloadAudioUrl.json` | CDN 音频与下载列表                  |
| 可选问卷题库  | 代码中硬编码路径 `questionConfig.json`（若存在）                                     | 问卷题目定义，用于 `survey_data`      |

## 1. `config/config.json`

顶层为 JSON 对象，常见字段：


| 字段              | 类型     | 说明                                                  |
| --------------- | ------ | --------------------------------------------------- |
| `user_profiles` | array  | 每个元素为一名用户的完整生成配置（见下节）                               |
| `questionCode`  | string | 问卷 code（如 `somni_vip`），写入 `survey_data.survey_code` |


### 1.1 `user_profiles[]` 单用户配置


| 字段                                                                               | 类型            | 说明                                                                                                                                                  |
| -------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `user_id`                                                                        | string        | Mongo 风格用户 ID                                                                                                                                       |
| `session_id`                                                                     | string        | 业务会话 ID                                                                                                                                             |
| `personalInformation`                                                            | object        | `type`（如 `M-L-C`）、`label`、`id`（人格维度文档 ID）                                                                                                           |
| `sleepProfile`                                                                   | string        | 睡眠叙事画像（长文本）                                                                                                                                         |
| `likelyNightSleepEvents`                                                         | array[string] | 允许的夜间事件中文名列表                                                                                                                                        |
| `preference`                                                                     | string        | 日常偏好叙事                                                                                                                                              |
| `fitnessProfile`                                                                 | string        | 体征叙事                                                                                                                                                |
| `sex`                                                                            | string        | 性别                                                                                                                                                  |
| `date`                                                                           | object        | `start` / `end`，`YYYY-MM-DD`，生成日期范围                                                                                                                 |
| `sleepTime` / `awakeTime`                                                        | object        | `min` / `max` 为**字符串时间数组**，元素如 `"22:00"`                                                                                                            |
| `deepSleep` / `awakeSleep` / `lightSleep` / `remSleep`                           | object        | `min` / `max` 为**整数数组**（百分比范围）                                                                                                                      |
| `sleepLatency` / `sleepEfficiency` / `nightAwakenings` / `nightWakeTotalMinutes` | object        | 同上，整数范围                                                                                                                                             |
| `fitness`                                                                        | object        | 含 `systolicPressure`、`diastolicPressure`、`bloodOxygen`、`heartRate`、`breathingRate`、`bodyMovement`、`fatigueIndex` 等，每项为 `{ "min": [n], "max": [m] }` |
| `sleepTemperature` / `sleepHumidity` / `sleepIlluminance`                        | object        | 睡眠环境适宜范围，`min`/`max` 为整数数组                                                                                                                          |
| `schedule`                                                                       | object        | `min_events_per_day`、`max_events_per_day`、`min_total_minutes_per_day`、`max_total_minutes_per_day`                                                   |

## 2. `health_data.json`（按日一条，数组文件）

单条记录：


| 字段                            | 类型     | 说明                                                 |
| ----------------------------- | ------ | -------------------------------------------------- |
| `user_id`                     | string | 用户 ID                                              |
| `record_date`                 | string | 业务日 `YYYY-MM-DD`                                   |
| `timestamp`                   | string | ISO UTC，常对齐上床时刻                                    |
| `dimension_type`              | string | 如 `sleep_quality_analysis`                         |
| `data_source`                 | string | 如 `health_monitor`                                 |
| `raw_data`                    | object | 睡眠摘要指标与关键时间点（见下表）                                  |
| `idf_data`                    | array  | 分期片段 `{ "stage", "start", "end" }`，时间为当日本地 `HH:MM` |
| `create_time` / `update_time` | string | ISO UTC                                            |
| `__v`                         | int    | 版本占位                                               |


### 2.1 `raw_data`


| 字段                                                                     | 类型     | 说明              |
| ---------------------------------------------------------------------- | ------ | --------------- |
| `apnea_count`                                                          | int    | 呼吸暂停相关计数        |
| `average_heartbeat` / `average_respiration`                            | int    | 平均心率、呼吸率        |
| `awake_ratio` / `deep_sleep_ratio` / `light_sleep_ratio` / `rem_ratio` | int    | 占 SPT 百分比       |
| `sleep_score`                                                          | int    | 综合睡眠分（可由环境规则重算） |
| `total_sleep_minutes`                                                  | int    | 总睡眠分钟           |
| `leave_bed_count` / `leave_bed_minutes` / `turnover_count`             | int    | 离床与翻身统计（对接可选）   |
| `bed_time` / `sleep_time` / `wake_time` / `wake_up_time`               | string | ISO UTC         |
| `sleep_latency` / `sleep_efficiency`                                   | int    | 入睡潜伏期（分钟）、效率（%） |


### 2.2 `idf_data[]`


| 字段              | 类型     | 说明                             |
| --------------- | ------ | ------------------------------ |
| `stage`         | string | 如 `awake`、`light`、`deep`、`rem` |
| `start` / `end` | string | `HH:MM`（本地）                    |

## 18. Python 模块中的配置型结构（非独立 JSON）

### 18.1 `personality_profile.PERSONALITY_PROFILES`

键为八类人格编码（如 `M-H-R`），值为 dict，常见键：`label`、`description`、`total_sleep_hours`、`sleep_latency`、`sleep_efficiency`、`night_awakenings`、`night_wake_total_minutes`、`turnover_count`、`apnea_count`、`avg_heartbeat`、`avg_respiration`、`leave_bed_count`、`leave_bed_duration`、`wake_after_sleep`、`noise_tolerance`、`hrv_adjustment`、`fatigue_index`、`stage_pattern` 等，用于随机范围与分期模式。

### 18.2 流水线步骤（`user_gen_pipeline.py`）

`USER_DATA_PIPELINE_ORDER` 涉及：`health` → `sleep_events` → `fitness` → `environment` → `vitals` → `event_feedback` → `schedule` → `ai_analysis` → `sleep_report` → `report_audios` 等（以源码注释为准）。
